# Tugas Praktikum Pemrograman Web

## Fetch API & Asynchronous JavaScript

Pada tugas praktikum minggu ini, kalian diminta mencoba Fetch API dari JSONPlaceholder menggunakan JavaScript asynchronous (`async/await`).

### Ketentuan Tugas

Implementasikan empat metode HTTP berikut:

- **GET** — Mengambil data dari API.
- **POST** — Menambahkan data.
- **PUT** — Memperbarui data.
- **DELETE** — Menghapus data.

Data yang diperoleh dari API harus di-mapping dan ditampilkan ke HTML menggunakan JavaScript DOM.

### Referensi

- JSONPlaceholder: https://jsonplaceholder.typicode.com/
- Dokumentasi Fetch API: https://developer.mozilla.org/en-US/docs/Web/API/Fetch_API

### Pengumpulan

1. Kerjakan tugas menggunakan HTML, CSS, dan JavaScript.
2. Pastikan keempat metode HTTP sudah dicoba.
3. Pastikan data atau hasil respons API dapat ditampilkan atau diperiksa.
