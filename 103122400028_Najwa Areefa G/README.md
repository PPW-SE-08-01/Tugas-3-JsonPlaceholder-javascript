## 📌 Deskripsi Tugas

Di tugas praktikum kali ini, aku ngerjain implementasi Fetch API dan Asynchronous JavaScript (async/await) pake mock server dari JSONPlaceholder.

Semua hasil data dan respon API diproses secara dinamis menggunakan manipulasi JavaScript DOM dan ditampilin langsung ke HTML.

## 🚀 Fitur & Implementasi HTTP Method

Di project ini, aku udah mengimplementasikan 4 metode HTTP utama:

GET: Mengambil Data

1. Mengambil list data dari JSONPlaceholder (misal: data posts/todos).
2. Data yang dapet dipetakan (mapping) lalu ditampilin ke elemen HTML.

POST: Menambahkan Data
1. Mengirim data baru ke API pake method POST.
2. Respon berhasil ditampilin langsung di layar sebagai bukti data sukses ditambah.

PUT: Memperbarui Data
1. Mengubah data tertentu berdasarkan ID.
2. Menampilkan respon pembaruan data ke DOM.

DELETE: Menghapus Data
1. Menghapus data dari server mockup berdasarkan ID.
2. Nampilin status/notifikasi kalau data udah berhasil dihapus.
